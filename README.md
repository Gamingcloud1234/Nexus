# NEXUS MC

Streamlit community-access portal.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Admin password
Create `.streamlit/secrets.toml` locally:

```toml
ADMIN_PASSWORD = "CHANGE_THIS_TO_A_STRONG_PASSWORD"
```

For Streamlit Community Cloud, add the same value under App Settings > Secrets.
